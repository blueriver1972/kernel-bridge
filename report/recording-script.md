설계 근거는 [demo-plan.md](demo-plan.md). 이 문서는 **찍는 순서와 실제 명령**이다.

## 0. 촬영 전 준비 (한 번만)

### 터미널
| 항목 | 값 | 이유 |
|---|---|---|
| 폰트 크기 | **18~20pt** | 기본 크기는 발표 화면에서 안 보인다 |
| 창 크기 | 100 × 30 | 너무 넓으면 글자가 작아진다 |
| 배경 | 어두운 색 | 프로젝터에서 눈이 덜 아프다 |
| 프롬프트 | 짧게 | 긴 경로가 매 줄 반복되면 지저분하다 |

WSL 프롬프트 단순화:
```bash
export PS1='\[\033[36m\]$ \[\033[0m\]'
```

### 녹화 도구
- **Windows 게임 바** (`Win`+`G`) — 설치 불필요, 창 단위
- **OBS Studio** — 편집 예정이면 이쪽

**전체 모니터가 아니라 터미널 창만** 잡는다.

### 클립은 따로 찍는다
한 번에 이어 찍으려다 실수하면 처음부터다. **클립당 파일 하나**로 나눠 찍고 나중에 붙인다.

## 클립 1 — 커널이란 무엇인가 (30초)

**화면**: 에디터로 `00-src/flash_attention_simplified.cu` (172줄)

```bash
code 00-src/flash_attention_simplified.cu
```

**말할 것**
- GPU 커널은 수천 개 스레드가 동시에 도는 함수다
- 이 파일은 어텐션 계산을 하나의 커널로 융합한 것 (FlashAttention 개념)
- **중요**: `#define Br 64`, `__shared__ float Kj[Bc][HEAD_DIM]` 를 가리키며
  → "이 숫자들이 **하드웨어 사양을 코드에 박아 넣은 것**입니다"

**하지 말 것**: 수식 설명. 관객은 알고리즘을 알 필요가 없다.

## 클립 3 — 성공했다는데 안 된다 ★ 핵심 (2분)

같은 스크립트가 이어서 2·3단계를 출력한다.

```
2단계 — 그 결과를 컴파일하면?
  ✗ softmax    error: 'cooperative_groups/reduce.h' file not found
  ✗ attention  error: 'hipblas.h' file not found
  ✗ flash      error: no matching function for call to 'rsqrtf'
  변환은 "성공"했지만 빌드는 안 된다

3단계 — 사람/LLM 이 수정한 뒤
  ✓ softmax    통과
  ✓ attention  통과
  ✓ flash      통과
```

**말할 것**
1. 변환기는 성공했다고 했는데 컴파일이 안 된다
2. 화면에 3건이지만 **실제로는 5회차에 걸쳐 11건**이었다
   (첫 에러가 컴파일을 중단시켜 파일당 하나씩만 보인다 — 화면 하단에 그렇게 적혀 있다)
3. 그중 **8건은 컴파일러가 알려준다** → LLM 이 자동으로 고칠 수 있다
4. **3건은 컴파일러가 아무 말도 안 한다** ← 여기가 핵심

**절대 하지 말 것**: 3건을 11건처럼 말하기. 화면과 말이 어긋나면 신뢰를 잃는다.

## 클립 4 — 조용히 틀리는 구간 (1분, 슬라이드)

터미널이 아니라 **코드 두 줄**을 띄운다.

```c
// 같은 파일 안에 두 관례가 공존한다
for (int offset = 16; offset > 0; offset /= 2)      // 워프가 32개라는 전제
for (int offset = warpSize / 2; offset > 0; ...)    // 런타임 값 (AMD=64)
```

**말할 것**
- NVIDIA는 한 조가 32명, AMD는 64명이다
- `16`은 "32의 절반"이라는 뜻인데 **글자로는 그게 안 보인다**
- 그대로 옮기면 **레인 절반만 계산하고 끝난다**
- 컴파일 통과, 크래시 없음, **답만 틀림**
- 문자열 치환으로는 도달할 수 없다 — **코드가 뭘 하는지 이해해야 한다**

## 클립 7 — 숫자 세 개 (30초, 슬라이드)

```
   자동으로 된 것       164 줄
   도구가 놓친 것        11 건
   사람이 판단한 것       3 건
```

**말할 것**
- 표본은 2,294줄 3파일이다. **이 비율을 업계 전체로 확대하지 않는다**
- 중요한 건 숫자가 아니라 **그 3건의 성격**이다
- 셋 다 "컴파일도 되고 크래시도 안 나면서 답만 틀리는" 부류다
- **정답 대조 장치가 없으면 발견조차 못 한다** ← 제품의 자리
