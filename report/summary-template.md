## 방법론 (숫자를 신뢰할 수 있는 이유)
- llm.c 내장 `validate_result`(tol 1e-4) · `benchmark_kernel` 을 그대로 사용. 자체 판정 아님
- flash 커널은 별도 하네스 작성 — CPU 레퍼런스 double 누적, 결정적 난수로
  양 플랫폼 입력을 비트 단위 동일하게 고정
- **정밀도 정합**: llm.c 는 A100/H100 에서 TF32 를 자동으로 켠다. 비교표 기준값은
  fp32 를 강제한 빌드끼리다 (TF32 값은 각주로만 병기)
- llm.c 커밋 `f1e2ace6` 고정. 컴파일 플래그 양쪽 동일
